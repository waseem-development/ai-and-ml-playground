✦ W H A T   I S   T H I S ? ✦

</div>

<br/>

CodeByPaxto: The AI & ML Playground is a beginner-friendly, hands-on course designed to take you from zero programming experience to your first real data analysis and machine learning project.

You don't need a Computer Science degree.

You don't need prior Python experience.

And you don't need to memorize a mountain of mathematics before writing your first useful program.

You learn each concept when you need it, then immediately use it.

Python
   ↓
Statistics & Math
   ↓
NumPy
   ↓
Pandas
   ↓
Visualization
   ↓
Exploratory Data Analysis
   ↓
Machine Learning
   ↓
Your Own Project 🚀
The philosophy

Learn → Build → Break → Debug → Understand → Build again.

Every topic has a purpose.

If a concept doesn't help you understand the next stage or solve a practical problem, it doesn't belong in the course.

<br/>

<div align="center">

"The goal isn't to turn you into a software engineer.

The goal is to give you enough technical power to work with your own data, research, and ideas."

Data cleaning
Statistical analysis
Visualizations

Basic predictive models

📊 Data Curious People

You've seen Python, AI, ML, and Data Science everywhere and want to move beyond:

"Yeah, I've heard of that."

toward:

"I actually built something with it."

<div align="center">

🧠   W H A T   Y O U ' L L   L E A R N

</div>

<br/>

By the end of the course, you'll have practical experience with:

🐍 Python — variables, data types, conditions, loops, functions, collections, files, errors, modules and debugging
📐 Statistics & Math — the concepts needed to understand and work with data
🔢 NumPy — arrays, dimensions, indexing, broadcasting, aggregation and numerical operations
🐼 Pandas — loading, exploring, cleaning, transforming and analyzing datasets
📈 Matplotlib & Seaborn — turning data into meaningful visualizations
🔍 Exploratory Data Analysis — understanding a dataset before jumping into modeling
🤖 Machine Learning — understanding the basic ML workflow and building your first models
🚀 Project Work — applying everything to a project you choose

The goal isn't to simply know the names of these tools.

It's to know when to use them, why you're using them, and how they fit together.

🗺️   C O U R S E   R O A D M A P

</div>

<br/>

Phase	What We Do
01 · Orientation	What computers are, how programming works, why Python, and your first programs
02 · Python Core	Variables, data types, operators, conditions, loops, collections, functions, files, errors and modules
03 · Statistics & Math	Descriptive statistics, probability fundamentals, distributions, sampling, correlation and the math needed for data science
04 · NumPy & Pandas	Numerical computing, arrays, DataFrames, indexing, filtering, cleaning and transformation
05 · Visualization & EDA	Matplotlib, Seaborn, charts, patterns, relationships, outliers and systematic dataset exploration
06 · Machine Learning	ML concepts, datasets, features, targets, training, evaluation and your first models
07 · Capstone	Choose a problem, find or collect data, analyze it, build a solution and present what you discovered

<div align="center">

🔬   H O W   W E   L E A R N

</div>

<br/>

This isn't a course where you watch someone type code for an hour and copy it.

The learning loop is:

        📖 Learn the idea
              ↓
        💻 Write the code
              ↓
        🧪 Experiment
              ↓
        💥 Something breaks
              ↓
        🔍 Debug it
              ↓
        🧠 Understand why
              ↓
        🚀 Build something
Expect to:
Write code during class
Make mistakes
Debug errors
Work with messy data
Ask questions
Experiment with different approaches
Build small things before bigger things
Use documentation and search instead of trying to memorize everything

Google is allowed.

In fact, learning how to find the right answer is part of becoming a good programmer.

You'll probably enjoy this if:
✅ You've opened an Excel sheet and thought "there has to be a better way."
✅ You want to understand what AI and ML actually involve.
✅ You have research or study data you'd like to analyze yourself.
✅ You want to learn Python through practical problems.
✅ You don't mind breaking things while learning.
✅ You're willing to experiment and look things up when you're stuck.
You don't need:
❌ A Computer Science degree
❌ Previous Python experience
❌ Advanced mathematics
❌ Expensive hardware
❌ To memorize every function in every library
